## 三条安全红线（很重要，请务必遵守）

1. **绝对不要改 `core/` 文件夹里的任何文件。** 公司同事每天都在用后台录入产品数据，
   那里面是活的生产代码，改坏了会直接影响公司业务。学习时**只看不改**。
2. **动手练习一律放在新建的练习模块里**（这份计划会用到 `learning_lab/`、
   `guestbook/`，以及项目外的 `d:\python练习\`），练完可以整个删掉，不影响正式代码。
3. **每次改完代码，跑一句自查命令**：
   ```
   git diff --stat HEAD -- core/
   ```
   **输出是空的**就说明没碰 core，安全。从第一天就开始养成这个习惯。

## 在开始之前：这个网站长什么样

```
你的浏览器
    ↓  输入 www.kl-filter.com
Cloudflare（负责加密、防攻击、把请求转进来）
    ↓  通过一条叫"隧道"的加密通道
公司的一台服务器（放在办公室，型号叫 fnOS 的 NAS）
    ↓
  nginx（门卫，决定这个请求该交给谁）
    ├── 要网页 → 直接给你 Vue 做好的页面文件
    └── 要数据 → 转给 Django 后端
                    ↓
                  MySQL 数据库（产品、分类、图片都存在这里）
```

- **前端（`frontend/`）**：用户看到的页面，Vue 3 写的。
- **后端（`core/` 等）**：Django + DRF 写的，存数据、算数据、把数据吐给前端。
- 再加上**部署**（把代码放到服务器上跑起来）和**运维**（备份、监控、出问题了怎么修）。

git diff --stat HEAD -- core/                                    # 应为空
